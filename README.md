# 🏌️ Digital Heroes

A full-stack web application built for the Digital Heroes assignment.

Digital Heroes allows users to participate in a golf-score-based monthly draw, manage their scores, support charities, manage subscriptions, and track their winnings. An admin panel provides tools for managing users, draws, charities, winners, and platform operations.
